# 꿈속의 과제 (Dream Homework)

과제를 하다 잠들어 버린 주인공이 꿈속 게임 세계에서 단서를 모아 과제를 끝내고 제출하는 도트 스타일 브라우저 게임입니다. (제작 중인 프로토타입)

## 실행하는 방법

1. 이 폴더 전체를 컴퓨터에 내려받습니다(zip이면 압축을 풉니다).
2. `index.html`을 더블클릭합니다. 크롬 같은 브라우저에서 열립니다.
3. 휴대폰에서는 가로 모드로 돌려서 플레이합니다. 휴대폰으로 테스트하려면 아래 Netlify로 올리는 게 가장 편합니다.

설치할 프로그램은 없습니다. 인터넷 연결도 필요 없습니다.

## 조작

- 방향키/WASD: 꾹 눌렀다 떼면 그 방향으로 발사됩니다(오래 누를수록 멀리 감). 휴대폰은 화면의 방향 버튼.
- E: 가까운 오브젝트와 상호작용 (휴대폰은 화면의 E 버튼)
- ESC: 설정 (휴대폰은 ⚙ 버튼)

## 폴더 구조

```
index.html      화면 뼈대
style.css       화면 모양
js/             게임 코드 (01~14번, 순서대로 불러옴)
archive/        안 쓰는 옛 코드와 백업
DESIGN.md       게임 설계와 현재 상태, 협업 규칙  ← AI에게 가장 먼저 읽히세요
HANDOFF.md      AI끼리 작업을 주고받는 메모
CHANGELOG.md    변경 기록
```

각 `js/` 파일이 무슨 일을 하는지는 `DESIGN.md`의 표와 각 파일 맨 위 설명에 적혀 있습니다.

## GitHub에 올리는 방법 (웹에서)

1. GitHub에서 새 저장소(New repository)를 만듭니다. 이름은 자유롭게, `Add a README`는 체크하지 않습니다.
2. 저장소 화면에서 **uploading an existing file** 링크를 누릅니다.
3. 이 폴더 안의 모든 것(`index.html`, `style.css`, `js` 폴더, `archive` 폴더, `.md` 파일들)을 드래그해서 올리고 **Commit changes**를 누릅니다. 폴더도 그대로 끌어다 놓으면 올라갑니다.
4. 고친 파일을 다시 올릴 때도 같은 방법(Add file → Upload files)으로 덮어쓰면 됩니다.

> 올릴 때는 압축 파일(zip) 자체가 아니라, **압축을 푼 안의 파일들**을 올려야 합니다.

## Netlify로 배포하는 방법

1. Netlify에서 **Add new site → Import an existing project**를 고르고 GitHub 저장소를 연결합니다.
2. 빌드 명령(Build command)은 **비워 두고**, 배포 폴더(Publish directory)도 비워 두거나 `.`으로 둡니다.
3. 배포가 끝나면 주소가 생기고, 이후에는 GitHub에 올릴 때마다 자동으로 새로 배포됩니다. 그 주소를 휴대폰에서 열어 테스트하세요.

## Claude / Gemini와 같이 작업하는 방법

1. 작업을 시킬 때마다 먼저 이렇게 말합니다.
   > `DESIGN.md`와 `HANDOFF.md`를 읽고, 거기 적힌 결정 사항을 바꾸지 말고 작업해 줘. 이번에 고칠 파일은 `js/○○.js`야. 끝나면 `HANDOFF.md`에 올릴 기록도 써 줘.
2. AI가 준 코드는 해당 파일에 덮어쓰고, 브라우저에서 한 번 돌려 본 뒤에 GitHub에 올립니다.
3. AI가 써 준 `HANDOFF.md` 기록을 파일 맨 위에 붙여 넣습니다. 다음에 다른 AI에게 일을 시킬 때 이 파일을 같이 보여 주면 이어서 작업합니다.
4. 두 AI가 같은 파일을 동시에 고치게 하지 마세요. 고칠 파일을 나눠서 시키는 게 안전합니다.
5. 토큰(사용량)을 아끼려면 AI에게 **전체 파일 대신 고칠 파일 하나와 두 문서만** 보여 주세요.

> 비밀 관리자 모드가 있습니다. 방법은 문서에 적지 않았고, 소스 코드에는 들어 있습니다. 저장소를 공개(Public)로 올리면 코드를 보는 사람은 알 수 있으니, 숨기고 싶다면 비공개(Private) 저장소를 쓰세요.
